PROFESSIONAL CLOUD ARCHITECT — LEGACY CASE STUDY (SAMPLE QUESTIONS)

Mountkirk Games Case Study

Company Overview
Mountkirk Games makes online, session-based, multiplayer games for mobile platforms. They have recently started expanding into a new global market and are building a new multiplayer game that they expect to be very popular. They plan to deploy the game's backend on Google Cloud so they can scale rapidly, process player telemetry in real time, and analyze global leaderboards.

Solution Concept
Mountkirk Games is building a new multiplayer game that expects millions of concurrent players worldwide. Player telemetry and game events are streamed from mobile clients to the cloud backend. The backend must scale dynamically based on player activity, maintain global leaderboards with low latency and strong consistency, and ingest telemetry into a real-time analytics platform.

Existing Technical Environment
- Previous games were hosted in a traditional colocation facility using Linux VMs, MySQL databases, and custom batch ETL scripts.
- Past launches suffered from scaling bottlenecks, unexpected traffic spikes causing 503 errors, and slow batch reporting.
- Development teams use Docker containers and want automated CI/CD pipelines with immutable deployment artifacts.

Business Requirements
- Increase global player reach across North America, Europe, and Asia with low-latency game servers.
- Scale compute and database capacity automatically to match unpredictable player concurrency.
- Provide real-time analytics on player behavior and game economy to game designers.
- Minimize operational overhead and pay only for resources consumed.

Technical Requirements
- Dynamically scale game backend servers across multiple regions based on demand.
- Maintain a single global frontend IP with HTTPS load balancing for REST API communication.
- Store high-velocity time-series telemetry (millions of events per minute) and support historical SQL analytics over petabytes of game data.
- Store transactional player state and global leaderboards with strong consistency.
- Isolate development, staging, and production environments while supporting repeatable infrastructure deployment.
